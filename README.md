# Calpe Networks media

Public images for Calpe Networks social media, used by Metricool via their raw links:
`https://raw.githubusercontent.com/calpenetworks-code/calpenetworks-media/main/<folder>/<file>`

- `posts/YYYY-MM/` feed posts and carousels (1080×1350)
- `stories/YYYY-MM/` Instagram/Facebook Stories (1080×1920)
- `highlights/` Instagram Highlight covers
- `print/` printable WhatsApp sign and QR code

Everything here is public.
